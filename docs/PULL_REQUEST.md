# Prepare a reproducible CPU graduation release

A clean checkout previously required a developer-only DVC remote/index mount. This change distributes the small frozen index with checksum validation, adds an offline DVC restoration pipeline, and starts the API through CPU Docker Compose with a fresh cache and optional OpenAI key. It also expands health/citation contracts, documents explicit missing-key errors and extends CI with artifact and container checks.

Validation: 81 deterministic tests passed in the existing Python 3.12.9 environment; Ruff and corpus checks passed. A separate clone built and started with a blank key and empty model cache, passed bilingual no-key HTTP checks, downloaded the pinned model and completed an authorized live semantic answer citing CC-91. Fresh native Windows pytest encountered an OpenSSL runtime failure; Docker is the validated clean-checkout path. Additional Linux test evidence and exact commands are recorded in the validation report.

The full graduation rubric is partially ready: RAGAS, five-run comparison/Registry evidence, BentoML/vLLM, monitoring, load testing and AWQ remain explicit gaps. No advanced results are fabricated. See [readiness](GRADUATION_READINESS.md), [validation](CLEAN_MACHINE_VALIDATION.md), [gaps](GRADUATION_GAPS.md) and [release notes](RELEASE_NOTES.md). Please keep this PR in draft until final CI checks and rubric review are complete.
